# IVS Calculator

**Live App:** https://ivs-calculator.vercel.app/

## Purpose
IVS Calculator helps the Admissions Department and Customer Support Agents quickly calculate student fees during calls with parents and new admissions.

## Key Features
- Parent & billing details section
- Add multiple students in one invoice
- Program + grade/level selection
- Discounts support (individual + global, where applicable)
- Registration fee handling
- Monthly billing selection + due date
- Final summary with totals
- Generate Invoice PDF

## Tech Stack
- React + TypeScript (Vite)
